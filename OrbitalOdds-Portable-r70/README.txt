Orbital Odds r70 - portable edition

Start the game with: Play Orbital Odds.bat

Keep the data folder next to OrbitalOdds.exe.
The game creates save.json and settings.json beside the executable, so progress stays in this folder or on the USB drive.
No installation or internet connection is required.

This build includes My Collection, Ball Market, the branching Challenges map, hover stat popovers, Mouse Invasion, and both bosses.
Ricochet Behemoth has 750 HP, Berserk, four staggered Bouncy Balls, and fights three owned balls in the Diamond arena.

To rebalance the game, edit data\catalog.json and press F5 outside a live match.
Challenge definitions are stored in data\challenges.json.
